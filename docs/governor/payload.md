## Required top-level fields

- `schemaVersion`
- `artifactIdentity`
- `context`
- `sourceWorkflowContext`
- `dataInputs`
- `renderingOptions`
- `validationPolicy`

## Identity

- `documentId` must match `^ORG-(GOV-(DS|AUP)|TRN-(TCL|TAK|TVR)|RSK-(RAF|ERL)|OPS-(UQR|DCN|SOP|RBK|DQR|ONB|OFB|LIC)|INT-(PIG|QAC|PMC|AAT)|MST-(SPEC|UG|WFE|SCL|PDX))-[0-9]{3}$`. The pattern encodes which category and code may pair, so a mismatched pairing fails at the schema, not later. The embedded code must also equal `artifactType`.
- **Never mint a Document ID.** Registry Owner issues them and the ID must already exist in the registry. If none exists, ask for one.
- `version` must match `^v[0-9]+\.[0-9]+$`.
- `classification` is one of: `Client-Facing`, `Controlled Signoff`, `Internal Working Document`.
- `layer` is one of: `Governance`, `Operational`, `Delivery`, `Administration`. It is determined by the artifact type, not chosen. A disagreement with config fails the run.
- `approvalStatus` is one of: `Approved`, `Draft`, `In Review`, `Retired`, `Superseded`. A new artifact is always `Draft`.

## Prohibited status aliases

Never use: `Final`, `Published`, `Archived`. They are not controlled values.

## Legal lifecycle transitions

| From | May become |
|---|---|
| Approved | `Superseded`, `Retired` |
| Draft | `In Review`, `Retired` |
| In Review | `Draft`, `Approved`, `Retired` |
| Retired | nothing, this state is terminal |
| Superseded | nothing, this state is terminal |

## Review dates

A review date must fall within the category interval measured from today, unless a documentation-owner override is attached. Do not fabricate an override to dodge the interval.

| Category | Interval |
|---|---|
| GOV | 6 months |
| INT | 12 months |
| MST | 12 months |
| OPS | 12 months |
| RSK | 6 months |
| TRN | 12 months |

## Rendering options

- `outputFileName` must match `^ORG - .+ - v[0-9]+\.[0-9]+\.docx$`.
- `packageName` is the footer package value and must not be empty.
