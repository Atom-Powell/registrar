## Default audiences

Use these unless the engagement gives you a reason to narrow them.

- **AUP**: Approved users, client leadership, security owner, compliance owner
- **DCN**: Client leadership, client contact, ORG delivery lead
- **DS**: Client leadership, security owner, Microsoft 365 admin, ORG delivery lead
- **PIG**: ORG delivery lead, engagement owner, documentation owner
- **RAF**: Client security owner, ORG deployer, ORG reviewer, risk owner
- **TAK**: Approved users, trainer, administrator
- **TCL**: Trainer, rollout coordinator, security owner, ORG delivery lead
- **UQR**: Approved end users and frontline managers

## What you do not decide

- Document IDs. Registry Owner issues them; the engine never mints one. If no ID exists, say so and stop.
- Section structure, clause selection, or placeholder values. Those belong to the drafting agent.
