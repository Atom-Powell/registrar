## Block types

These are the only block types the engine renders. Any other value is rejected before rendering is attempted.

- `paragraph`
- `h2`
- `h3`
- `table`
- `radioQuestion`
- `clauseInsertion`
- `aggregationTable`
- `copyReadyMessage`
- `warnCallout`
- `bulletList`

The schema does not restrict which of the fields below belong to which block type: they are declared as optional siblings of every block, not per type. Each block type uses only the subset it needs; consult the sample AGRs for how each block type is actually shaped.

| Field | Type | Description |
|---|---|---|
| `text` | string or null | not set |
| `internalOnly` | boolean or null | Marks a block as an internal-only note (remove-before-client-use). QA-SF-09 fails any internalOnly block in a client-facing artifact at promotion; internally-classified artifacts may retain it, and it renders per its blockType (author internal notes as an already-supported block, e.g. paragraph). |
| `clauseId` | string or null | Required when blockType=clauseInsertion. Engine inserts canonical text from clause-library.json and verifies the SHA-256; Governor-supplied clause text is ignored by design so paraphrase drift is structurally impossible. |
| `aggregationSource` | string or null | For an aggregationTable block: the config source to project. clauseLibrary is live; placeholderDictionary is reserved and fails closed until the PDX slice. |
| `rows` | array or null | not set |
| `columnHeaders` | array or null | not set |
| `items` | array or null | not set |
| `question` | object or null | not set |

## Character policy

Free text and placeholder values may contain only the characters below. A prohibited character fails the run in both draft and promotion. Use a plain hyphen, straight quotes, and three periods.

- Printable Basic Latin.
- Printable Latin-1 Supplement, excluding the non-breaking space and the soft hyphen, so accented names are fine.
- Approved glyphs: `○`
